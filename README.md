# Retaining Wall Drainage and Permit Notes

A homeowner reference explaining why hydrostatic water pressure overturns retaining walls, when walls near four feet require permits and structural engineering, and how segmental concrete blocks compare with natural boulders, citing CMHA, ICC, USGS, and 811.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — retaining wall engineering and drainage overview: `https://ahmetalkan.github.io/retaining-wall-drainage-and-permit-notes/`
- Subpage — drainage gravel, drain pipes, and preventing hydrostatic bulging: `https://ahmetalkan.github.io/retaining-wall-drainage-and-permit-notes/hydrostatic-pressure-and-backfill.html`
- Subpage — measuring wall height for building permits and engineering: `https://ahmetalkan.github.io/retaining-wall-drainage-and-permit-notes/four-foot-wall-permit-triggers.html`
- Subpage — comparing segmental concrete blocks and natural boulder walls: `https://ahmetalkan.github.io/retaining-wall-drainage-and-permit-notes/segmental-block-vs-boulder-walls.html`

It cites public pages on [retainingwalllab.com](https://retainingwalllab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
